Can't load player data

This page fetches players.json from its own folder, and browsers block that fetch when the file is opened directly (a file:// URL).

Serve this folder over local HTTP instead, then open the printed address. For example, from a terminal in this folder:

python3 -m http.server 8000

then visit http://localhost:8000/rankings.html.
